# Security policy

Report vulnerabilities to **security@kryptic.dev**.

Do not open a public GitHub issue, pull request, or discussion for a security
report.

The full policy (scope, response targets, and how CVE IDs are requested) is:

https://kryptic.dev/security/disclosure

`security.txt`: https://kryptic.dev/.well-known/security.txt

Kryptic is not a CVE Numbering Authority. There is no paid bug bounty.
